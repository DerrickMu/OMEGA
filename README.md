# OMEGA

This repository provides selected data and code used in our study on electric vehicle (EV) defect risk management.

## Contents

* `Preliminary\_experiment`: Data used in the preliminary defect extraction experiment.
* `RoBERTa\_classifiers\_pool`: Data used for developing the risk classifiers.
* `Recall\_data\_results`: Data used in the application to official EV recall data.
* `LLM-based few-shot NER for EV defect extraction`: Code for EV defect information extraction using an LLM-based few-shot NER approach.
* `Risk classifier based on RoBERTa and SMOTE-Tomek`: Code for EV defect risk classification using RoBERTa and SMOTE-Tomek.

## Data availability

Due to data-sharing restrictions, only selected and processed data are publicly provided.

## Note

This repository is intended to support the reproducibility and transparency of the corresponding OMEGA manuscript.
